Windows 原生程序

Qt 雷达回放

桌面程序

在 Windows 桌面端检索、播放与比较 Oxford RobotCar 数据。支持 0.25–16 倍速、轨迹 / 位姿 / 误差对比和 CSV 导出。

输入 → 输出：7,203 帧同步雷达与双目图像、7 种已保存位姿方法 → 可交互对比和 CSV 数据。

核心技术：Qt Widgets、C++。网页雷达回放是同仓库的独立静态演示，不是桌面程序。

Qt 设备工作台

桌面程序

用模拟器发送设备记录，工作台接收后绘制曲线、保存与重载数据，并转发给接收端查看。

输入 → 输出：4,096 条 Intel Berkeley 实验室温湿度与电压记录 → TCP JSON 数据流、曲线、持久化记录和转发显示。

核心技术：Qt Widgets、C++、TCP JSON、DLL 模块。数据来自记录模拟，不代表真实设备接入。
